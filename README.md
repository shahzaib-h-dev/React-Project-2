# ✈️ Travel Journal - React App

A dynamic and reusable React application built to explore and master the core concepts of React, focusing on component architecture, props, and list rendering in a `React-Section-Two` module[cite: 1].

## 🚀 Tech Stack
* **Frontend:** React (TypeScript)
* **Package Manager:** Bun
* **Build Tool:** Vite

## 🧠 Key Learning Concepts
This repository covers several fundamental and advanced React concepts:
* **Component Architecture:** Structuring UI with a Header and reusable Entry components to solve code duplication problems[cite: 1].
* **Mastering Props:** Working with props destructuring, handling non-string props, and passing/spreading objects directly into components[cite: 1].
* **Dynamic List Rendering:** Utilizing the array `.map()` method to efficiently render multiple components from data arrays[cite: 1].
* **React Fundamentals:** Understanding the mechanics of the `key` prop and importing static assets[cite: 1].
